# Google Sheets import files

Generated by `node scripts/export-sheets.mjs` from the dashboard dataset.

- `*.csv` — one file per tab (text, version-controlled).
- `Management-PMKT.xlsx` — all 7 tabs in one workbook (generated; not committed).
  Regenerate it by installing the optional `xlsx` package, then running the
  exporter: `npm i xlsx --no-save && node scripts/export-sheets.mjs`.

## Fastest way to populate your sheet (one step)

Use the **workbook** to fill all tabs at once:

1. Open your Google Sheet → **File → Import**.
2. **Upload** `Management-PMKT.xlsx`.
3. Import location: **Replace spreadsheet** → **Import data**.

This replaces the (empty) tabs with all 7 populated tabs, with the correct
names — including fixing the `ReadlinessMetrics` → `ReadinessMetrics` typo.

## Or import tab-by-tab (CSV)

For each tab: select the tab → **File → Import** → **Upload** the matching
`<Tab>.csv` → import location **Replace current sheet**.

## After importing

- Recommended: set sharing to **Anyone with the link → Viewer** (the dashboard
  only needs read access; "Editor" lets anyone with the link change your data).
- The dashboard is already pointed at this sheet, so it will show your data on
  the next load.

Column definitions for every tab: see [`../docs/GOOGLE_SHEETS.md`](../docs/GOOGLE_SHEETS.md).
